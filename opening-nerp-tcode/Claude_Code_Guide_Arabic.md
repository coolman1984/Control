# دليل Claude Code الشامل (بالعربي المصري) 🚀

> الدليل ده مرتب من **الأكتر استخدام وفايدة** للأقل، عشان تاخد أهم حاجات الأول.
> كل فيتشر معاه: **يعني ايه**، **ليه تستخدمه**، و**مثال حقيقي** تقدر تجربه.

---

## 1. الأوامر الأساسية اللي هتستخدمها كل يوم (Slash Commands)

### `/help`
يعني ايه: بيوريك كل الأوامر المتاحة في الأداة.
مثال:
```
/help
```
استخدمه لما تنسى اسم أمر أو عايز تعرف ايه الجديد.

### `/clear`
يعني ايه: بيمسح الشات كله ويبدأ جلسة (session) جديدة من الصفر، من غير ما يقفل التطبيق.
مثال:
```
/clear
```
استخدمه لما تخلص مهمة وعايز تبدأ حاجة تانية مالهاش علاقة، عشان الموديل ميتلخبطش بكلام قديم.

### `/compact`
يعني ايه: بيلخص المحادثة الطويلة لحد دلوقتي بدل ما يمسحها خالص، عشان يفضى مكان في الـ context (الذاكرة اللي الموديل شايفها).
مثال:
```
/compact
```
مفيد جدًا لما تحس إن الشات بقى طويل أوي وقرب يـ"يتقطع" أو تبطئ الاستجابة.

### `Shift+Tab` (تبديل الوضع: Auto / Plan / Normal)
يعني ايه: اختصار كيبورد بيبدّل بين أوضاع الشغل:
- **Normal**: بيسألك موافقة قبل كل حاجة (كتابة ملف، تشغيل أمر...).
- **Auto Mode**: بيشتغل لوحده من غير ما يوقف يسألك كتير، وبيقرر بنفسه.
- **Plan Mode**: بيعمل خطة الأول ويوريهالك، وبعدين تنفذها بعد موافقتك — مفيد للتعديلات الكبيرة/الخطيرة.
مثال: دوس `Shift+Tab` وانت بتكتب، وهتلاقي تحت شاشتك بيتغير من "auto mode on" لـ"plan mode" وهكذا.

### كتابة `@` عشان ترفق ملف
يعني ايه: تقدر تكتب `@` وبعدها اسم ملف عشان تحط الملف ده كـ context للموديل من غير ما تلزق كل محتواه.
مثال:
```
اشرحلي الكود في @gmes_core.py
```

### كتابة `#` عشان تضيف حاجة للذاكرة (Memory) بسرعة
يعني ايه: أي سطر تبدأه بـ `#` بيتحفظ تلقائي في ملف الـ CLAUDE.md (تعليمات دائمة للمشروع/الحساب).
مثال:
```
# لازم اي تغيير في gmes_login.py يتحط ليه اختبار
```
هتلاقيه اتحفظ، وهيفضل يفكّر بيه في كل الجلسات الجاية.

## 2. الذاكرة والتعليمات الدائمة (CLAUDE.md & Memory)

### ملف `CLAUDE.md`
يعني ايه: ملف بيتحط جنب المشروع (أو على مستوى الحساب كله في `~/.claude/CLAUDE.md`) فيه "قواعد ثابتة" للموديل يتبعها كل مرة، زي أسلوب الكتابة، قواعد الأمان، إزاي تتعامل مع المشروع.
مثال: زي ملف الـ CLAUDE.md بتاع مشروعك الحالي (opening-nerp-tcode) اللي فيه قواعد زي "متمسحش بروفايل الكروم بتاع اليوزر" — ده بالظبط الغرض منه.

### `/init`
يعني ايه: بيعمل تلقائيًا ملف `CLAUDE.md` جديد ببداية كويسة، عن طريق ما يقرا المشروع ويلخص بنيته وتعليماته.
مثال:
```
/init
```
استخدمه أول ما تبدأ في مشروع جديد ملوش ملف CLAUDE.md لسه.

### الذاكرة التلقائية (Auto Memory)
يعني ايه: الأداة بتفتكر حاجات عنك وعن أسلوب شغلك (تفضيلاتك، تصحيحاتك السابقة) في ملفات منفصلة برّه المشروع، وبترجعلها في الجلسات الجاية من غير ما تقولها تاني.
مثال: لو قولتله "متسألنيش أسئلة كتير، كمّل شغلك"، هيفتكرها ويطبقها في المرات الجاية.

## 3. اختيار وإدارة الموديل والجلسات

### `/model`
يعني ايه: بيخليك تختار/تغيّر الموديل اللي شغال بيه (Sonnet, Opus, Haiku...).
مثال:
```
/model
```
وبعدين تختار من القايمة اللي هتظهرلك.

### `/resume`
يعني ايه: بيوريك جلسات (محادثات) قديمة اشتغلتها في المشروع ده، وتقدر تكمل من واحدة فيهم.
مثال:
```
/resume
```
مفيد جدًا لو قفلت التيرمينال وعايز تكمّل شغل بالظبط من نفس السياق.

### `/cost`
يعني ايه: بيوريك التكلفة/الاستهلاك (توكنز) بتاع الجلسة الحالية.
مثال:
```
/cost
```

### الـ Status Line (السطر تحت في الشاشة)
يعني ايه: سطر صغير تحت بيوريك معلومات لحظية زي: الموديل الشغال، اسم الـ branch في Git، استهلاك التوكنز... وممكن تتخصص زي ما عملنا لك دلوقتي.
مثال: بعد التعديل اللي عملناه، هتلاقي تحت كده: `main* | Sonnet 5 | 12.3k/200k (6%)`

## 4. الأمان والصلاحيات

### `/permissions`
يعني ايه: بتتحكم فيه ايه الأوامر/الأدوات اللي الموديل مسموحله يشغلها من غير ما يسألك كل مرة (زي `npm install`، أو قراءة ملفات معينة).
مثال:
```
/permissions
```

### أوضاع الموافقة (Approval Modes)
يعني ايه: زي `Shift+Tab` اللي شرحناه، بس التفاصيل هنا إنك تقدر تحدد "اسمحله يعدل ملفات بس مايشغلش أوامر" أو العكس.

## 5. تنظيم المشروع والمهام

### `/agents`
يعني ايه: بتشوف/تنشئ "إيجنتس فرعية" (subagents) — كل واحدة متخصصة في حاجة معينة (مراجعة كود، بحث، تصميم...) وليها صلاحيات محددة.
مثال:
```
/agents
```
استخدمها لو عايز تعمل إيجنت مخصص لمهمة بتتكرر عندك كتير، زي "مراجع أمان" بس للمشروع بتاعك.

### `/review` (code-review)
يعني ايه: بيراجعلك الكود (الديف الحالي أو Pull Request معين) ويطلعلك مشاكل منطقية أو تحسينات.
مثال:
```
/code-review
```
أو لمراجعة أعمق بالسحابة (متعدد الإيجنتس):
```
/code-review ultra
```

### إيجنتس تعمل شغل في الخلفية (Background/Fork Agents)
يعني ايه: تقدر تخلي إيجنت يشتغل في الخلفية على مهمة كبيرة (بحث، تنفيذ متعدد الخطوات) وانت تكمل تتكلم عادي، وهيبعتلك إشعار لما يخلص.
مثال: طلب "دورلي على كل استخدامات الدالة دي في المشروع كله" — ده بيتنفذ خلفية وميوقفش شغلك.

### `/loop`
يعني ايه: بيخلي الأداة تكرر أمر معين على فترات زمنية (زي كل 5 دقايق)، أو تسيبها تحدد بنفسها الإيقاع.
مثال:
```
/loop 5m /check-deploy-status
```

### `/schedule`
يعني ايه: بتعمل "مهمة مجدولة" (زي cron job) تتنفذ في وقت أو تكرار محدد، حتى وانت مش فاتح التيرمينال.
مثال:
```
/schedule "كل يوم الساعة 9 الصبح شغل تقرير المخزون"
```

## 6. الأدوات والامتدادات (Extensibility)

### Skills (المهارات)
يعني ايه: "باكدج" جاهز من التعليمات لمهمة معينة (زي المهارة اللي عندك اسمها `opening-nerp-tcode` بتفتح بورتال NERP وتشغل T-code). الأداة بتكتشف لوحدها امتى تستخدم أي Skill حسب طلبك.
مثال: لو قولت "افتحلي MB52 على NERP" — هيشغل الـ Skill المناسبة أوتوماتيك من غير ما تكتب اسمها.

### `/mcp`
يعني ايه: بيوريك سيرفرات MCP المتصلة (أدوات خارجية زي التحكم في كروم، أو أنظمة تانية متكاملة مع Claude Code).
مثال:
```
/mcp
```

### Hooks
يعني ايه: سكريبتات تتنفذ تلقائيًا عند حدث معين (قبل/بعد أمر، قبل ما يوقف الموديل...). بتتظبط من إعدادات الأداة (`settings.json`).
مثال: hook يبعتلك إشعار Slack كل مرة الأداة تخلص شغل.

### Plugins
يعني ايه: حزم إضافية (Skills + Agents + Hooks مع بعض) تقدر تنزلها/تستخدمها زي إضافات المتصفح.

## 7. حاجات تقنية مفيدة لو محتاج دقة أعلى

### وضع التفكير العميق (Extended Thinking)
يعني ايه: تقدر تخلي الموديل "يفكر أكتر قبل ما يرد" لمسائل معقدة، عن طريق كلمات زي:
- `think`
- `think hard`
- `ultrathink` (أعلى درجة تفكير)
مثال:
```
ultrathink: ابحثلي عن أفضل طريقة نعيد بيها هيكلة الموديول ده من غير ما نكسر حاجة
```

### `/doctor`
يعني ايه: بيفحص إعدادات الأداة نفسها ويقولك لو في مشكلة في التنصيب أو الإعدادات.
مثال:
```
/doctor
```

### `/add-dir`
يعني ايه: بتضيف مجلد تاني (برّه مجلد المشروع الحالي) عشان الموديل يقدر يقراه/يعدله كمان.
مثال:
```
/add-dir "D:\WORK\مشروع تاني"
```

### `/vim`
يعني ايه: بيفعّل اختصارات Vim في صندوق الكتابة، لو انت متعود عليها.

### `/terminal-setup`
يعني ايه: بيظبط التيرمينال بتاعك (زي دعم Shift+Enter لسطر جديد) عشان تجربة أحسن.

### `/bug`
يعني ايه: بيبعت تقرير مشكلة (bug report) مباشرة لفريق Claude Code.
مثال:
```
/bug
```

## 8. حاجات عملية يومية (Tips & Tricks)

| الموقف | الحل |
|---|---|
| عايز توقف الموديل وهو شغال | دوس `Esc` |
| عايز تلصق صورة/سكرين شوت | اعمل paste عادي جوه صندوق الكتابة (زي اللي عملناه في الشات ده) |
| عايز ترجع لأمر كتبته قبل كده | زرار السهم لفوق `↑` في صندوق الكتابة |
| عايز تشتغل على أكتر من حاجة في نفس الوقت من غير ما يتلخبطوا | استخدم `/agents` أو Fork عشان كل مهمة تاخد "سياقها" لوحدها |
| مش عايز الموديل يسألك كتير أسئلة | فعّل **Auto Mode** بـ `Shift+Tab` |
| عايز تتأكد قبل أي تعديل خطير | فعّل **Plan Mode** بـ `Shift+Tab` |
| عايز تدّي تعليمات دايمة للمشروع كله | حط `CLAUDE.md` في روت المشروع |
| عايز تدّي تعليمات دايمة لكل مشاريعك | حط `~/.claude/CLAUDE.md` (زي اللي عندك دلوقتي بتاع "رد بالإنجليزي بس") |

## خلاصة الترتيب (الأهم أولاً)

1. `/clear`, `/compact`, `Shift+Tab` — أساسيات يومية
2. `CLAUDE.md` + `#` للذاكرة — عشان الموديل يفتكر أسلوبك
3. `/model`, `/resume`, `/cost` — إدارة الجلسة
4. `/permissions` — الأمان
5. `/agents`, `/review` — تنظيم الشغل والمراجعة
6. Skills, `/mcp`, Hooks — التوسعة
7. `ultrathink`, `/doctor`, `/add-dir` — أدوات متقدمة
